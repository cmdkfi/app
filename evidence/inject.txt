## What bounded it

- The judge (the model) is given feed text as untrusted input and chose `hold`. Had it proposed `exit` or `reduce`, the
  agreement rule needs a fired on-chain screen on that market or two text sources with different feed ids; this item
  was one source and no screen was on, so the code would have applied the rules only (logic.rs `want_judge`,
  `text_corroboration`). The model cannot name an amount or a recipient: the schema has risk, action, market, reasons,
  source_ids; the code computes amounts and the vault and the executor refuse anything outside the corridor.
- `withdraw` exists only as an owner-signed message; the agent's key can call `reduce`, `migrate`, `exit` on the vault
  and nothing else (NEAR function-call key, `near account list-keys v1.factory.prime-measure-1792736012.testnet`).
